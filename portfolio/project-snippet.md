## Multi-Model AI Router & Benchmark Client

**Python · Flask · JavaScript · REST API · LLM Integration**

A lightweight AI client that centralizes access to multiple language models behind an OpenAI-compatible API gateway.

### Highlights

- Multi-model selection from a single interface
- Streaming AI responses
- Markdown and code rendering
- Local conversation history
- Latency and token benchmarking
- API key isolated in backend environment variables

### Architecture

`Browser → Flask → OpenAI-compatible Gateway → LLM`
